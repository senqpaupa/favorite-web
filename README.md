# Учёт ремонтов (favorie)

Простое веб-приложение для мастерской: приём в ремонт → заполнение работ и запчастей → авто-ИТОГО → печать квитанции/чека с реквизитами.

- **Local-first**: данные лежат в браузере (IndexedDB), приложение полностью работает **без интернета**.
- **Облако (Supabase) — по желанию**: бэкап и доступ с телефона. Настраивается в «Настройках».
- **Печать**: через браузер (принтер или «Печать в PDF»), два формата — **A4** и **термочек 80 мм**.
- Чистая статика: HTML/CSS/JS-модули, без сборщика.

## Запуск локально

Из-за ES-модулей нужен любой статический сервер (открывать `file://` нельзя):

```bash
# любой из вариантов
python3 -m http.server 5173
# или
npx serve -l 5173
```

Открыть http://localhost:5173

## Как пользоваться

1. **Настройки** → впиши реквизиты мастерской (ИНН/ОГРН/адрес/телефон/приёмщик). Они попадут в шапку чека.
2. **Заказы → + Новый заказ** → заполни поля приёмки → **🧾 Приёмная квитанция** (печать при приёме).
3. Когда ремонт готов → открой заказ → добавь строки **Работ** и **Запчастей** (ИТОГО считается само) → **✓ Готов + печать** или **🧾 Печать чека/акта**.
4. **Клиенты** — база с историей обращений. **Аналитика** — выручка за период.

## Подключение Supabase (бесплатно, необязательно)

1. Заведи проект на https://supabase.com (бесплатный тариф, карта не нужна).
2. **SQL Editor** → вставь и выполни `supabase/schema.sql`.
3. **Project Settings → API** → скопируй `Project URL` и `anon public` ключ.
4. В приложении: **Настройки → Облако** → вставь URL и ключ → «Проверить связь» → «Сохранить облако».
5. Дальше синхронизация идёт автоматически (и по кнопке «Синхронизировать» в шапке).

> Нюанс бесплатного тарифа: проект «засыпает» после недели полного простоя (будится одной кнопкой). При ежедневной работе не мешает.
> Безопасность: по умолчанию доступ по anon-ключу (см. комментарии в `schema.sql`). Для входа по паролю — включить Supabase Auth.

## Бесплатный хостинг (чтобы открывать по ссылке)

Это статические файлы — подойдёт любой бесплатный статик-хостинг:

- **Netlify** / **Cloudflare Pages**: перетащить папку или подключить репозиторий.
- **GitHub Pages**: запушить в репозиторий, включить Pages.

Установка «как приложение»: в браузере на странице → меню → «Установить приложение» (PWA), появится ярлык.

## Бэкап

**Настройки → Бэкап**: «Скачать бэкап» (JSON) и «Загрузить бэкап». Делай периодически, если не подключил облако.

## Структура

```
index.html            оболочка + навигация
css/styles.css        стили
js/app.js             роутер и статус синка
js/db.js              IndexedDB (локальное хранилище)
js/models.js          модель данных, статусы, расчёт ИТОГО
js/print.js           шаблоны печати (A4 и термочек)
js/sync.js            синхронизация с Supabase (REST)
js/util.js            хелперы
js/views/*.js         экраны: заказы, заказ, клиенты, аналитика, настройки
supabase/schema.sql   таблицы для облака
sw.js, manifest       PWA (оффлайн, установка)
```
